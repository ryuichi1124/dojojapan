# DŌJŌ JAPAN 予約管理・会員登録マニュアル

更新日: 2026-05-26

## 1. 基本方針

予約システム本体は `dojo-japan.jp` 上の会員予約ページです。公式LINEは入口として使いますが、LINEを使っていない会員でも同じ予約ページを使えます。

会員登録はスタッフが行います。会員本人に自由登録させる運用にはしません。

## 2. 管理画面

管理画面:

```text
https://dojojapan.pages.dev/dj-ops-6271-kuroobi/
```

管理画面を開くと管理IDとパスワードを求められます。ログイン後、予約表と会員管理を操作できます。

## 3. 予約をスタッフが入れる手順

1. 管理画面にログインする。
2. 週間予約表から予約を入れたい枠をタップする。
3. ポップアップ内の「会員を追加」で会員を検索する。
4. 対象会員の「追加」を押す。
5. 確認画面で内容を確認し「実行」を押す。

未登録者や体験者を仮で入れる場合:

1. 枠をタップする。
2. 「未登録の名前で追加」に名前を入力する。
3. 「名前で追加」を押す。

注意:

- 定員は1枠6名です。
- 18:00枠は作成しない運用です。
- 休会中、削除済みの会員は予約追加リストに出ません。
- 準会員は月間上限を超えると予約できません。ただし管理者が「特別追加枠」を付けた場合は、その月だけ予約可能数が増えます。

## 4. 会員登録の手順

1. 管理画面右上の「会員管理」を押す。
2. 以下を入力する。
   - 会員コード
   - 表示名
   - 会員種別
   - ステータス
   - 特別追加枠（今月のみ）
   - 休会予定日
   - 電話番号下4桁
   - 誕生日 MMDD
3. 「保存」を押す。
4. 確認画面で「実行」を押す。

会員コードは `DJ-012` のように管理します。自動で次の番号が入りますが、必要に応じて変更できます。

特別追加枠は、準会員の通常上限にその月だけ追加する予約数です。例: 準会員 月2で特別追加枠を `1` にすると、その月だけ月3回まで予約できます。翌月は通常上限に戻ります。正会員は無制限なので入力不要です。

休会予定日を入力すると、その日以降は自動で休会扱いになり、予約追加リストにも会員予約画面にも出ません。

ステータス:

- 通常: 予約可能
- 休会中: 会員管理には残るが予約不可
- 削除: 会員一覧から非表示。過去予約履歴は残る

## 5. 会員さんへ予約案内を送る手順

会員登録後、会員管理一覧の対象会員で「案内」を押します。

「案内」を押すと以下が自動で行われます。

- 既存の個別予約URLを使う
- PINは変更しない
- 会員さんへ送る案内文をクリップボードへコピー

コピーされる文面には以下が含まれます。

- 個別予約URLを開いてPINを入力する案内
- 個別予約URL
- 会員コード
- PINは以前案内したものを使う案内
- 次回以降の入力省略の案内
- LINEを使わない場合の予約URL

スタッフはコピーされた文面を公式LINE、SMS、メールなどで会員さんへ送ります。

初回案内、PIN忘れ、ログインできない場合は、会員一覧の「編集」を開き、編集画面内の「リセット&再案内」を押します。この操作だけが新しいPINを発行し、古いPINとログイン状態を無効化します。

## 6. 会員さん側の初回利用

LINEを使う場合:

1. スタッフから届いた個別予約URLを開く。
2. PINを入力する。
3. 「この端末で次回から入力を省略」にチェックする。
4. ログイン後、空き枠から予約する。

2回目以降:

1. 公式LINEメニューの「予約」を押す。
2. 前回と同じ端末であれば入力を省略して予約画面に入れる。

LINEを使わない場合:

1. スタッフから届いた予約URLをブラウザで開く。
2. 会員コードとPIN、または個別予約URLとPINでログインする。
3. 必要であれば「この端末で次回から入力を省略」にチェックする。

## 7. 会員さんが予約する手順

1. 会員予約ページにログインする。
2. 「空き枠」で日付を選ぶ。
3. 希望時間の「予約する」を押す。
4. 確認画面で「実行」を押す。

表示される情報:

- 他の会員の名前は表示しません。
- 何名予約済みかは表示せず、空き数または満席のみ表示します。

## 8. 変更・キャンセル

会員さん側:

1. 会員予約ページにログインする。
2. 「自分の予約」から変更またはキャンセルを押す。
3. 確認画面で実行する。

スタッフ側:

1. 管理画面で対象枠を開く。
2. 予約済み一覧から削除したい予約の `×` を押す。
3. 確認画面で実行する。

注意:

- 会員本人の変更・キャンセルは締切時間を過ぎるとできません。
- 会員本人の新規予約は開始1時間前まで可能です。
- 開始3時間前を過ぎた枠を予約する場合、予約前に「この予約はあとから変更・キャンセルできません」という確認を表示します。
- スタッフ側は締切時間に関係なく、必要に応じて代理削除できます。

## 9. 休会・再開・削除

休会にする:

1. 会員管理を開く。
2. 対象会員の「編集」を押す。
3. 編集画面内の「休会」を押す。
4. 確認画面で実行する。

休会予定日で自動休会にする:

1. 会員管理を開く。
2. 対象会員の「編集」を押す。
3. 休会予定日を入力する。
4. 「保存」を押す。
5. 入力した日以降、自動で休会扱いになります。

休会中の挙動:

- 会員管理には表示されます。
- 予約追加リストには出ません。
- 会員予約ページから予約できません。
- URL/PIN発行、案内文作成はできません。

再開する:

1. 会員管理で対象会員の「編集」を押す。
2. 編集画面内の「再開」を押す。
3. 確認画面で実行する。

削除する:

1. 会員管理で対象会員の「編集」を押す。
2. 編集画面内の「削除」を押す。
3. 確認画面で実行する。

削除は物理削除ではありません。予約履歴を守るため、内部的には削除済みステータスとして保存します。

## 10. PINを忘れた場合

スタッフが会員管理で対象会員の「編集」を開き、「リセット&再案内」を押します。

- `案内`: PINを変更せず、公式LINE向けの案内文だけコピー
- `リセット&再案内`: 新しいPINを発行し、公式LINE向けの案内文をコピー

「リセット&再案内」を押した場合のみ、古いPINは使えなくなります。新しく送ったPINだけを案内してください。

## 11. LINEを使わない会員

LINEを使わない会員には、スタッフが「案内」または「PIN」で作成した内容をSMS、メール、紙、口頭で渡します。

LINEを使わない場合でも予約ページ、会員コード、PINがあれば予約できます。

## 12. セキュリティ運用

最低限守ること:

- 管理IDとパスワードを会員に教えない。
- PINを会員本人以外に送らない。
- PINを送る相手のLINEトーク、電話番号、メールを間違えない。
- 休会中・削除済み会員にはPINを発行しない。
- 会員がスマホを紛失した場合はPINを再発行する。
- 会員がLINEアカウントを変えた場合もPINを再発行する。

システム側の保護:

- PINは平文保存しません。
- PIN失敗が続くと一時ロックされます。
- 会員は自分の予約しか見られません。
- 会員側には他会員の名前を表示しません。
- 休会中・削除済み会員は予約できません。

## 13. よくある対応

### LINEメニューから入れない

初回ログインが完了していない可能性があります。スタッフが「案内」を再発行し、個別予約URLとPINを送ってください。

### PINが違うと言われる

古いPINを使っている可能性があります。スタッフが「編集」から「リセット&再案内」を押して再発行してください。

### 会員コードがわからない

管理画面の会員管理で名前検索し、会員コードを確認してください。

### 休会中の会員が予約したい

会員管理で「再開」を押して通常ステータスに戻してから予約してください。

### LINEをやめたい

LINEは入口なので、予約ページURLとPINをSMS、メール、紙で渡せば運用を継続できます。
