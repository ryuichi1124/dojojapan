ADMIN OPERATION MANUAL

予約管理の
基本操作

管理画面で予約枠を確認し、会員予約・未登録予約・キャンセル・枠メモを管理します。会員さん側に見えるのは空き数のみです。

01

毎日の基本操作

1

管理画面へログイン

管理者専用URLを開き、管理IDとパスワードでログインします。ログイン前は予約表・会員情報は表示されません。

2

予約枠を選択

週表示から対象の日時をタップします。選択した枠の予約人数、予約済み会員、追加候補、枠メモが表示されます。

3

会員を追加

会員検索で名前または会員コードを入力し、対象会員の「追加」を押します。準会員は月間上限、休会中は予約不可です。

4

未登録の名前で追加

体験・ビジターなど会員登録前の方は「未登録の名前で追加」から名前だけで枠に入れます。

5

予約削除・枠メモ

予約済み一覧の削除ボタンで管理者側からいつでも削除できます。枠メモは入力後、自動でD1に保存されます。

重要ルール

  • 1枠の定員は6名です。
  • 18:00枠は作成しません。
  • 同じ会員は同じ枠に重複予約できません。
  • 管理者側の削除は締切に関係なく可能です。

反映確認

追加・削除後は予約済み一覧と人数表示が変わります。通信エラーが出た場合は、再読み込みして予約表に反映されているか確認してください。

同時予約への対策

同じ枠へ7件同時に予約が入っても、6件だけ確定し、7件目は満席エラーになります。同じ会員の二重タップも1件だけ確定します。

MEMBER REGISTRATION

会員登録と
LINE案内

会員登録はスタッフ側で行います。登録後、公式LINEのトークで会員さんへ予約URLとPINを案内します。

02

会員登録から案内送信まで

1. 会員管理

管理画面右上の「会員管理」を開きます。会員一覧には「編集」「案内」「予約一覧」が表示されます。

2. 会員情報入力

会員コード、表示名、会員種別、ステータス、電話番号下4桁、誕生日MMDDを入力します。

3. 保存

「保存」を押して登録します。特別追加枠は今月だけ有効です。休会予定日はその日以降に自動休会となります。

4. 案内

対象会員の「案内」を押すと、PINを再発行し、LINEで送る案内文がコピーされます。

LINEで送る流れ

  • 会員さんが公式LINEを友だち追加
  • 会員さんがお名前をDOJOへ送信
  • スタッフが会員管理で対象会員を確認
  • 「案内」を押してコピーされた文面を返信

案内時の注意

  • 送信相手を間違えない。
  • PINは最新のものだけを案内する。
  • 休会中・削除済み会員には案内を送らない。
  • ログインできない場合は「案内」を再発行する。

編集画面で行う操作

休会・再開・削除

一覧からは操作せず、対象会員の「編集」を開いてから行います。削除しても過去の予約履歴は残ります。

予約一覧

会員一覧の「予約一覧」から、その会員の現在の予約を確認できます。問い合わせ対応時に使います。

会員さんへの説明

初回だけPINを入力し、「この端末で次回から入力を省略」にチェックしてもらうと、次回から公式LINEメニューの予約ボタンで入りやすくなります。
